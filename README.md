# NAATI CCL Vietnamese ⇄ English – Study Pack

Fast-track material for the NAATI Credentialed Community Language (CCL) test (5 bonus points for skilled visas such as subclass 189).

## Test format

Based on NAATI's official Vietnamese sample dialogues and the CCL booklet in [materials/](materials/). Rules change, so confirm on the [NAATI CCL page](https://www.naati.com.au/other-information/ccl-testing/) before your test.

| Item | Detail |
|---|---|
| Dialogues | 2 recorded dialogues, each from a **different** topic, ~**300 words** each (~150 English + ~150 Vietnamese) |
| Segments | 12–16 segments per dialogue, strictly alternating, **English speaker always starts**. Each segment ≤ **35 words**; a mix of long (20–35), medium and very short ones (e.g. "How does 3.30 sound?") |
| Word count | NAATI counts a Vietnamese segment by the length of its **English translation** |
| Flow | You **activate each segment yourself**. A chime sounds shortly after the segment ends (≈2 s in the official sample audio; the booklet says up to 5 s); start interpreting after the chime. Then activate the next segment |
| Time | ~20 minutes for the test + ~15 minutes to read instructions |
| Marks | 45 per dialogue. **Pass = 63/90 overall AND at least 29/45 in each dialogue.** 58–62.5 = marginal fail; < 58 or < 29 in either dialogue = clear fail |
| Repeats | You may ask for a segment to be repeated before you start interpreting it. **The first repeat in each dialogue is free**; further repeats may be penalised |
| Corrections | Allowed: preface with *"Sorry, I'll just say that part again"*, then give the corrected version once. Long pauses and repeated reworking lose marks |
| Notes | Pen and **blank** paper allowed |
| Delivery | Online, video- and audio-recorded, computer/laptop only, no dictionary |

### How it is marked

At least two examiners mark independently, looking for:
- **Accuracy:** is the information correct?
- **Distortions:** has the meaning been changed?
- **Omissions:** has information been left out?
- **Insertions:** has information been added?
- **Language quality and register:** grammar, pronunciation, vocabulary and politeness in both languages.

## Common ways to lose marks

1. **Omissions** – dropping a number, a date, a name, a condition ("only if…"), a negation, or a qualifier ("about", "maybe", "usually").
2. **Distortions** – wrong meaning (e.g. "fortnightly" → "hằng tuần").
3. **Register** – too casual. The Vietnamese speaker in the official samples addresses the professional as *ông/bà (+ name)*, *thưa ông/bà*, with *dạ / vâng / ạ*. When you interpret the professional, use *ông/bà* or *anh/chị* consistently. **Never use *bạn*.**
4. **Unnatural language** – word-for-word English calques in Vietnamese, or Vietnamese structure in English. NAATI's own model answers render by meaning: *tôi chẳng bao giờ cấm cháu về nhà* → "my door is always open"; *chết đói* → "starving".
5. **Self-corrections & hesitations** – one quick correction is fine; repeated ones cost marks.
6. **Adding information** – don't explain or expand; interpret only what was said.

## How to use these files

1. Read [00-core-vocab.md](00-core-vocab.md) first – numbers, dates, connectors and Australian systems that appear in **every** topic.
2. Read [official-samples-notes.md](official-samples-notes.md) – what the real Vietnamese dialogues sound like, plus errors to avoid from third-party material.
3. For each topic file in [topics/](topics/):
   - Cover the right-hand column of the vocab table and translate aloud, both directions.
   - Each topic has **3 dialogues in the real exam layout** (12–16 segments, ≤35 words each, word count shown). Dialogue 3 copies the simpler, everyday style of NAATI's official samples, which is closest to the real test. Dialogues 1–2 are a bit denser in vocabulary.
   - Read each segment **aloud** or have someone read it to you. Cover the translation, interpret aloud, then compare.
   - Record yourself; start speaking within ~2 s. Never ask for more than one repeat per dialogue.
4. **Use the official audio** in [materials/](materials/) (`Vietnamese_*.mp3`). It plays continuously, with only ~2 s, a chime and ~2 s between segments, so **pause the player at each chime**, interpret, then resume. Check yourself against the matching `Vietnamese - <Topic>.pdf`.
5. Repeat the dialogues 3× over a week (spaced repetition). By the 3rd time you should be fluent and not need notes.

### 2-week plan

| Days | Do |
|---|---|
| 1 | Core vocab + official samples notes + all 4 official MP3s (as a baseline; record yourself) |
| 2–7 | 2 topics/day: vocab drill → Dialogue 3 → Dialogues 1–2 |
| 8–13 | Second pass: 2 topics/day, dialogues only, recorded, no looking at notes |
| 14 | Mock: pick 2 random dialogues from different topics, no pauses except at chimes, one repeat max per dialogue; redo the official MP3s and compare with day 1 |

## Note-taking symbols (quick system)

| Symbol | Meaning | Symbol | Meaning |
|---|---|---|---|
| ↑ | increase / tăng | ↓ | decrease / giảm |
| → | lead to / dẫn đến | ← | because / vì |
| ✓ | yes / agree / đồng ý | ✗ | no / not / không |
| ? | question / hỏi | ! | important / quan trọng |
| $ | money / tiền / chi phí | w/ | with / với |
| w/o | without / không có | ∵ / ∴ | because / therefore |
| 2wk | fortnight / 2 tuần | Dr | doctor / bác sĩ |
| appt | appointment / cuộc hẹn | gov | government / chính phủ |

Write numbers, dates, names immediately – those are the most commonly lost details.
