# NAATI CCL Vietnamese ⇄ English – Study Pack

Fast-track material for the NAATI Credentialed Community Language (CCL) test (5 bonus points for skilled visas such as subclass 189).

## Test format (quick recap)

| Item | Detail |
|---|---|
| Dialogues | 2 recorded dialogues, each ~300–350 words, on a community topic |
| Segments | Each dialogue is split into segments of **max ~35 words**, alternating English ⇄ Vietnamese |
| Your job | After the chime, interpret each segment into the other language, consecutively |
| Marks | 45 per dialogue, total 90; **63/90 to pass** |
| Repeats | You may request repeats, but each one may cost marks – aim to need none |
| Delivery | Online (video), recorded, no dictionary; note-taking on the provided whiteboard/paper is allowed |

Official info: https://www.naati.com.au/other-information/ccl-testing/ (always check for current rules).

## Common ways to lose marks

1. **Omissions** – dropping a number, a date, a name, a condition ("only if…"), a negation, or a qualifier ("about", "maybe", "usually").
2. **Distortions** – wrong meaning (e.g. "fortnightly" → "hằng tuần").
3. **Register** – too casual. Vietnamese speaker addressing a professional: use *dạ / thưa / ạ* naturally; render the professional's English politely (*anh/chị*, *ông/bà*).
4. **Unnatural language** – word-for-word English calques in Vietnamese, or Vietnamese structure in English.
5. **Self-corrections & hesitations** – one quick correction is fine; repeated ones cost marks.
6. **Adding information** – don't explain or expand; interpret only what was said.

## How to use these files

1. Read [00-core-vocab.md](00-core-vocab.md) first – numbers, dates, connectors and Australian systems that appear in **every** topic.
2. For each topic file in [topics/](topics/):
   - Cover the right-hand column of the vocab table and translate aloud, both directions.
   - Read each dialogue segment **aloud**, cover the translation, interpret aloud, then compare.
   - Record yourself on phone; time yourself – start speaking within ~2 s of the chime.
3. Repeat the dialogues 3× over a week (spaced repetition). By the 3rd time you should be fluent and not need notes.

## Note-taking symbols (quick system)

| Symbol | Meaning | Symbol | Meaning |
|---|---|---|---|
| ↑ | increase / tăng | ↓ | decrease / giảm |
| → | lead to / dẫn đến | ← | because / vì |
| ✓ | yes / agree / đồng ý | ✗ | no / not / không |
| ? | question / hỏi | ! | important / quan trọng |
| $ | money / tiền / chi phí | w/ | with / với |
| w/o | without / không có | ∵ / ∴ | because / therefore |
| 2wk | fortnight / 2 tuần | Dr | doctor / bác sĩ |
| appt | appointment / cuộc hẹn | gov | government / chính phủ |

Write numbers, dates, names immediately – those are the most commonly lost details.
