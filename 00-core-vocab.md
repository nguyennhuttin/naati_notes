# 00 – Core Vocabulary (appears in every topic)

Master this file first. These are the words that cause the most lost marks because they're frequent and small.

## 1. Interpreter / dialogue openers & politeness

| English | Vietnamese |
|---|---|
| Good morning, how can I help you? | Chào anh/chị, tôi có thể giúp gì cho anh/chị? |
| Please take a seat. | Mời anh/chị ngồi. |
| What brings you here today? | Hôm nay anh/chị đến đây có việc gì? |
| Thank you for coming in. | Cảm ơn anh/chị đã đến. |
| I understand your concern. | Tôi hiểu sự lo lắng của anh/chị. |
| I'm sorry to hear that. | Tôi rất tiếc khi nghe điều đó. |
| Don't worry. | Anh/chị đừng lo. |
| Could you tell me…? | Anh/chị có thể cho tôi biết…? |
| Let me explain. | Để tôi giải thích. |
| Is there anything else? | Anh/chị còn câu hỏi gì nữa không? |
| Thank you so much for your help. | Cảm ơn anh/chị rất nhiều đã giúp đỡ. |
| Dạ, cháu chào cô/chú. | Hello. (just "Hello" – don't translate the kinship terms) |
| Dạ vâng / Dạ được ạ | Yes / Okay, sure |
| Thưa bác sĩ / thưa luật sư | Doctor, … / (omit "thưa" or render as polite tone) |
| Xin lỗi cho tôi hỏi | Excuse me, may I ask… |
| Tôi không rõ lắm | I'm not quite sure / I don't really understand |
| Phiền anh/chị… | Would you mind… / Could you please… |

> **Tip:** Vietnamese uses kinship pronouns (*cô, chú, bác, con, cháu, em*). Interpret into English as I/you. Going EN → VI, use *anh/chị* (or *ông/bà* for elderly) as a safe neutral choice. Keep it consistent within one dialogue.

**Dates:** "the 3rd of March" → *ngày 3 tháng 3*. Vietnamese order is day → month → year. "Thứ Hai/Ba/Tư/Năm/Sáu/Bảy, Chủ Nhật" = Mon–Sun.
